What I do

Building + breaking

Building web apps
I build apps that keep businesses running daily. Clearly defined functionality and technical specification are the basis of good software. To build upon that, I use modern software development principles to create reliable, functional and modular solutions.
Agentic development
I direct agents to build software, while retaining a high degree of maintainability and professionality. I guide the agents to execute tasks in a pragmatic way by codifying the silent rules of development to the agentic pipeline and by keeping a human in the loop. Data protection and agent permissions are also important topics to me.
Integrations
I build system integrations, such as various different PIM, ERP, WMS, CMS. Integrations are like any other software, but at their core, some aspects rise above others; consistency in data transformations, monitoring, adequate logging and focus on performance. Designing outwards facing API's for applications as well as API clients and API wrappers for third party services.
Security review
As a security researcher I mainly do code analysis, review and vulnerability POC and reporting, as well as incident response, which includes patching vulnerable systems, regulatory reporting and coordination. Occasionally I also do penetration testing on closed-source systems and take part in bug bounty programs.
