What I do

Building + breaking

Building web apps
The kinds of apps businesses run on every day. I'm most focused on simplicity and modularity. Clearly defined functionality and technical specification are the basis of good software. To build upon that, I use modern software development principles to create reliable and functional solutions.
Agentic development
Directing agents to build software, while retaining a high degree of maintainability and professionality. I guide agents to execute tasks in a pragmatic way by codifying the silent rules of development to the agentic pipeline and by keeping a human in the loop. Data protection and agent permissions are also important topics to me.
Integrations
1. System integrations, where applications are wired to talk to the systems they sit next to, such as various different PIM, ERP, WMS, CMS. Integrations are like any other software, but at their core, some aspects rise above others; consistency in data transformations, monitoring, adequate logging and focus on performance. 2. Designing outwards facing API's for applications. 3. API clients and API wrappers.
Security review
As a security researcher I mainly do code analysis, review and vulnerability POC and reporting, as well as incident response, which includes patching vulnerable systems, regulatory reporting and coordination. Occasionally I also do penetration testing on closed-source systems and take part in bug bounty programs.

How I work

Paradigms over stacks

Languages come and go. What carries over is knowing which paradigm fits the problem. I care more about how software is made, tested and deployed than about any one stack.
